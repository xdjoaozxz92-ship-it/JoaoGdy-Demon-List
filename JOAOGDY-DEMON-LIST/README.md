# JOAOGDY DEMON LIST

Projeto baseado no template Geometry Dash Shitty List, de TheShittyList. Os créditos originais foram mantidos no site.

## Abrir no Windows

1. Tenha o Node.js instalado.
2. Dê dois cliques em `INICIAR JOAOGDY DEMON LIST.bat`.
3. O site abre em `http://localhost:8000`.
4. Para desligar o site local, feche a janela do servidor.

## Personalização já feita

- Nome JOAOGDY DEMON LIST.
- Tema azul neon e preto.
- Idioma da interface em português (Brasil).
- Lista, ranking e roleta do template original.
- Editor/owner configurado como JOAOGDY.

## Importante

Os três níveis que aparecem inicialmente são exemplos de demonstração, não uma Demon List oficial. Substitua os arquivos JSON em `data/` por níveis e recordes reais antes de publicar.

Para adicionar um nível, crie um JSON seguindo o formato dos arquivos de exemplo em `data/` e inclua o nome do arquivo (sem `.json`) em `data/_list.json`.

O botão de envio de recordes e o ícone do Discord ainda precisam receber os links reais da comunidade/formulário.

O template original mantém os créditos de TheShittyList: https://tsl.pages.dev/
